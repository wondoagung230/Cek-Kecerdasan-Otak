# Kuis Pendidikan Multiplayer (SD + SMP + SMA)

**Total 353 soal** siap pakai.

## Fitur Utama
- 353 soal (SD, SMP, SMA, Bahasa Inggris, Pengetahuan Umum)
- Pilihan jawaban diacak setiap muncul
- Timer 20 detik (otomatis stop jika semua pemain sudah jawab)
- Soal otomatis ganti setelah 3 detik
- Batas 15 soal → poin di-reset
- Background GIF + musik relax
- Filter kategori lengkap

## Cara Menjalankan
```bash
cd quiz-game
npm install
npm start
```
- Host: http://localhost:3000/host.html
- Player: http://IP_KOMPUTER:3000/player.html
